新增组合方案

A 的结构，C 的即时效果

左侧保留分类导航。编辑器页在右边展示正文与源码示例，调整字体、字号和代码隔行底色时即时更新；其他分类收起预览，让设置列表保持宽敞。

打开 A＋C 组合预览 →

A · 左侧分类

接近 Obsidian 的结构。分类常驻左边，设置分区和说明留在右边，适合后续增加设置项。

打开 A 预览 →

B · 紧凑标签

保留现有顶部标签的使用习惯。常规设置采用两列分组，减少滚动，整体更紧凑。

打开 B 预览 →

C · 右侧抽屉

正文仍然可见，设置从右侧打开。切到编辑器分类调整字号，可直接查看左侧文档效果。

打开 C 预览 →

建议优先看 A。分类更容易查找，和目前的文档应用风格一致。B 的改动较小；C 更适合频繁调整阅读外观。也可以选 A 的结构，搭配 C 的字体效果预览。
