# README 截图素材

六张 PNG 截于 2026-10-12，来自 **PaperNest v0.2.5 Windows 便携版**的实际 WebView2 桌面窗口。程序与正式发行的 EXE 字节一致，使用独立配置、WebView2 数据目录及演示文档，未修改产品界面代码。

- 程序 SHA-256：`3e9fabdd5a267bdafa31ca7398679fba233e48f4264f2f50f57da868688cc286`。
- 窗口内容尺寸：1120 × 760 逻辑像素；Windows 缩放 125%，PNG 为 1402 × 952，包含可见窗口边框。
- 界面语言：简体中文；阅读字号 16 px，源码字号 15 px；侧栏宽度 220 px；本轮演示关闭仅显示 Markdown 的筛选，展示 JSON 文件入口。
- 截图直接捕获可见窗口区域，未拼接、修饰或生成界面；没有个人文档、用户名路径及鼠标标记。

复拍时，将 `demo/` 复制到不含个人信息的演示目录，使用独立的程序、配置和用户数据目录打开文件，展开“笔记”和“项目”目录。截图前清除路径提示与菜单外的悬浮提示，并移开鼠标；设置面板中的配置路径也应保持为无用户名的演示路径。使用物理像素捕获可见窗口边界，避免 Windows DPI 缩放导致裁切或文字模糊。
