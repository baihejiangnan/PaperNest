# Miku Cream 设计规则

PaperNest 以阅读内容为视觉中心，保留轻量编辑入口。本文描述当前界面约束；实际样式值以 [`src/styles.css`](../src/styles.css)、[`src/miku-cream.ts`](../src/miku-cream.ts) 和可配置项为准。

## 色彩与层级

| 用途 | 默认值或来源 | 规则 |
| --- | --- | --- |
| 文档背景 | `--bg: #fcfbfa` | 长文阅读区域保持明亮、低干扰。 |
| 正文文字 | `--fg: #141413` | 保证标题、正文和交互文字可辨。 |
| 工具栏与侧栏 | `--bar-bg: #f3f0ee` | 通过浅色背景和边框与正文分区。 |
| 强调色 | `--accent: #39c5bb` | 主要用于当前项、焦点和操作反馈；用户设置可覆盖。 |
| 悬停/分隔 | `--hover`、`--border` | 同类控件保持一致，危险操作单独使用警示色。 |

Markdown 代码块与普通文件的 Code 模式共用 `src/miku-cream.ts` 中的语义高亮；不要为不同后缀另造一套颜色主题。字体、字号和隔行颜色来自设置，不应在新组件里硬编码为第二套配置。

## 布局与状态

- 主窗口的标题栏放常用操作；文件树与大纲共用左侧空间，文档区域随窗口宽度伸缩。侧栏收起后内容占满剩余空间。
- 文件树以文件夹图标、层级缩进和细竖线表示目录关系；当前文档、悬停和键盘焦点要能区分。右键菜单的“删除”使用警示色，并在实际删除前确认。
- “在新窗口中打开”是同一进程内的单文档窗口：不显示文件树、大纲或标签栏，保留该文档需要的阅读与轻量编辑操作。
- 图片以容器宽度为上限等比例缩放。放大预览为只读遮罩，关闭时返回原焦点；滚轮缩放、拖动和关闭操作不改写文档。
- Markdown 渲染与 Code 模式的切换应保持阅读位置，避免在长文中意外跳回顶部。非 Markdown 文件直接使用 Code 模式，不显示“可切换回渲染”的状态。

## 交互检查

新增控件应有可理解的文本或可访问名称、可见焦点、禁用状态说明，并随界面语言更新。菜单、对话框和图片遮罩要支持 Esc 关闭；点击暗色背景关闭图片预览时不要触发正文编辑。内容样式与应用框架样式分开维护，优先复用现有 CSS 变量和组件状态。
