# README 截图素材

六张 PNG 截于 2026-10-08，来自 PaperNest v0.1.5 源码的实际 Windows WebView2 桌面窗口，不是网页示意图。仅临时应用标识与运行配置隔离，未修改产品界面代码；图片直接截取可见窗口边界，未拼接或修饰内容。

- 窗口内容尺寸：1120 × 720 逻辑像素；Windows 缩放 125%，PNG 包含窗口边框。
- 界面语言：简体中文；阅读字号与源码字号均为 14 px；侧栏宽度 210 px。
- `main-light.png`、`main-dark.png`、`markdown-source.png` 使用同一份 [阅读示例](demo/阅读示例.md)。
- `code-json.png` 使用 [配置示例](demo/配置示例.json)，其中键值仅为演示内容，不是 PaperNest 设置文件格式。
- `settings-editor.png` 展示设置的“编辑器”分类。
- `readme-details.png` 使用加入本轮截图前的项目 README 副本，展开“文件树”区块。

复拍时，将 `demo/` 内容复制到不含个人信息的演示目录，补入项目 README 及其 `branding/icon-master.png`；用独立配置打开文档，展开“笔记”和“项目”目录，依次切换主题、源码视图、JSON 和设置。截图前移开鼠标，确认没有路径提示或其他窗口遮挡。设置面板会显示配置文件位置，因此运行目录也应使用无用户名的演示路径。
